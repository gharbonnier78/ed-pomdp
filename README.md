# ED-POMDP Research Edition v1.0 — Step 1: Scientific Foundations

This repository is the reviewer-oriented scientific foundation for **Evidence-Driven Partially Observable Markov Decision Processes applied to software release assurance**.

## Status

Step 1 is a **methods, preregistration, and research-programme package**. It does not claim operational superiority, real-data calibration, or cross-domain validation.

## Documents

- `paper/main.tex` — main scientific paper source
- `research_program/research_program.tex` — multi-year research programme source
- `survey/related_work.tex` — related-work survey and novelty boundary
- `reviewer/reviewer_companion.tex` — response to initial reviewer concerns
- `ontology/evidence_ontology.tex` — evidence ontology
- `appendix/mathematical_appendix.tex` — mathematical and experimental appendix

Compiled PDFs are generated by GitHub Actions.

## Build

```bash
make all
make check
```

Requirements: `latexmk`, `pdflatex`, and Python 3. Bibliography is embedded for portable builds.

## Scientific posture

The primary domain is software release assurance. Biometrics and UAV active perception are future external-validity studies. The central open question is whether evidence-quality and observation models can be identified and calibrated robustly from real assurance data.

## Repository roadmap

- Step 1: scientific foundations (this package)
- Step 1.1: epistemic foundations and identifiability note
- Step 2: matched-budget benchmark and demonstrators
- Step 3: industrial calibration and retrospective replay
- Step 4: shadow deployment and governed evaluation
